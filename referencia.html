Pull Request — FEAT: Imágenes de productos

Resumen

Este PR implementa soporte completo de imágenes para productos coleccionables. Cada producto puede tener una imagen asociada que se muestra en el inventario. Las imágenes se cargan manualmente por el usuario (Hot Wheels, Funko) y se almacenan localmente en el sistema de archivos. La arquitectura queda preparada para que en producción el almacenamiento se reemplace por Supabase Storage sin modificar el dominio.

Motivación

Para coleccionables, la imagen es parte fundamental de la identificación del producto. Un Hot Wheels Corvette o un Funko de Goku son objetos visuales — el nombre solo no es suficiente para identificarlos en el punto de venta.

Cambios por capa

Domain

Producto.cs — se agregó la propiedad ImagePath (nullable string, private set) y el método AsignarImagePath(string? imagePath) para asignar la imagen respetando el encapsulamiento de la entidad.

IImageStorageService.cs (archivo nuevo) — Outbound Port definido en Domain con dos métodos: SaveImageAsync(string? rutaOrigen) que guarda una imagen desde el sistema de archivos y devuelve el nombre del archivo guardado, y GetFullPath(string? imageName) que reconstruye la ruta absoluta a partir del nombre guardado.

ProductoBusquedaResult.cs — se agregó string? ImagePath al record de resultado de búsqueda para transportar la referencia de imagen hasta la UI.

Infrastructure

ProductoConfiguration.cs — se agregó el mapeo de la columna image_path TEXT NULL en la tabla product usando Fluent API.

LocalImageStorageService.cs (archivo nuevo) — implementación del port IImageStorageService para entorno de desarrollo. Al recibir la ruta de origen del archivo, genera un nombre único con Guid.NewGuid(), copia el archivo a %LocalAppData%\TeejoshSystem\images\ y devuelve solo el nombre del archivo. La carpeta se crea automáticamente si no existe.

InfrastructureServiceRegistration.cs — se registró IImageStorageService como Singleton apuntando a LocalImageStorageService.

Configuraciones de detalles (FunkoConfiguration, HotWheelsConfiguration, TcgConfiguration, ToyConfiguration, VariosConfiguration) — se agregó builder.Property<string>("Discriminator").IsRequired(false) en todas las configuraciones para resolver un bug de SQLite donde EF Core generaba la columna Discriminator como NOT NULL, impidiendo insertar registros en las tablas de detalle.

Migración EF Core — se regeneró la migración InitialCreate limpia con todos los cambios anteriores aplicados.

Application

ProductoBusquedaDto.cs — se agregó string? ImagePath para transportar la ruta absoluta de la imagen desde el handler hasta el ViewModel.

BuscarProductosQueryHandler.cs — se inyectó IImageStorageService para convertir el nombre de archivo guardado en BD a ruta absoluta antes de mapear al DTO. Esto evita que la UI dependa de la estructura de carpetas interna.

CrearProductoCommand.cs — se agregó string? ImagePath como propiedad opcional del comando, representando la ruta temporal del archivo seleccionado por el usuario.

CrearProductoCommandHandler.cs — se inyectó IImageStorageService. Antes de persistir el producto, llama a SaveImageAsync con la ruta del archivo seleccionado, obtiene el nombre guardado y lo asigna al producto con AsignarImagePath.

ActualizarProductoCommand.cs — se agregó string? ImagePath al record del comando para soportar cambio de imagen en edición.

ActualizarProductoCommandHandler.cs — se inyectó IImageStorageService. Si el comando trae una nueva imagen, la guarda y actualiza el producto antes de persistir.

ProductoDetalladoDto.cs — se agregó string? ImagePath para que la pantalla de edición pueda cargar la imagen actual del producto.

ObtenerProductosPorIdQueryHandler.cs — se mapea producto.ImagePath al DTO de detallado.

AvaloniaUI

PathToImageConverter.cs (archivo nuevo) — IValueConverter que convierte una ruta de archivo (string) a un Bitmap de Avalonia. Si la ruta es nula, el archivo no existe o la conversión falla, devuelve null sin lanzar excepción, permitiendo que el placeholder se muestre automáticamente.

CrearProductoView.axaml — se cambió x:DataType por x:CompileBindings="False" para compatibilidad con ObjectConverters. Se agregó un bloque de selección de imagen debajo del campo Unidades: muestra un botón "Seleccionar imagen" cuando no hay imagen seleccionada, y el nombre del archivo con un botón "Quitar" cuando sí hay una seleccionada.

CrearProductoViewModel.cs — se agregaron las propiedades ImagePath (ruta temporal origen) e ImageNombre (nombre para mostrar en UI), el comando SeleccionarImagenAsync que abre el StorageProvider de Avalonia para seleccionar archivos PNG/JPG/JPEG, y el comando QuitarImagen. La propiedad ImagePath se incluye en ConstruirCommand().

EditarProductoView.axaml — se agregó el mismo bloque de selección de imagen que en Crear. Se cambió a x:CompileBindings="False".

EditarProductoViewModel.cs — se inyectó IImageStorageService. Al cargar el producto (CargarProductoAsync), resuelve la ruta absoluta de la imagen actual con GetFullPath y la muestra en UI. Se agregaron las propiedades ImagePath, ImageNombre e ImagePathActual, y los comandos SeleccionarImagenAsync y QuitarImagen.

GestionarProductosViewModel.cs — se inyectó IImageStorageService para pasarlo al constructor de EditarProductoViewModel al navegar a edición.

InventarioView.axaml — se cambió AutoGenerateColumns="True" a "False" para controlar las columnas manualmente. Se agregó PathToImageConverter en Resources. Se añadió una columna de imagen como primera columna del DataGrid: muestra la imagen en miniatura (50×50px) si existe, o un placeholder gris con ícono si no hay imagen.

Esquema de base de datos

Se agregó una columna a la tabla product:

ALTER TABLE product ADD COLUMN
image_path TEXT NULL;

Los registros existentes quedan con NULL — no hay impacto en datos previos.

Comportamiento esperado

Al crear o editar un producto, el usuario puede seleccionar una imagen desde su equipo. El sistema la copia a %LocalAppData%\TeejoshSystem\images\ con un nombre único (UUID) y guarda solo ese nombre en la BD. En el inventario, los productos con imagen muestran una miniatura de 50×50px. Los productos sin imagen muestran un recuadro gris con ícono de imagen.

Criterios de aceptación cumplidos

  • ✅ Columna image_path TEXT NULL agregada a tabla product
  • ✅ Migración generada y aplicada
  • ✅ IImageStorageService como Outbound Port con LocalImageStorageService
  • ✅ El formulario de Crear/Editar tiene control para seleccionar imagen
  • ✅ La vista de Inventario muestra la imagen del producto si existe
  • ✅ Si no hay imagen, muestra un placeholder

Cómo probar

  1. Clonar la rama y ejecutar dotnet ef database update desde la raíz del proyecto.
  2. Correr con dotnet run --project TeejoshSystem.AvaloniaUI.
  3. Crear un producto de cualquier tipo y seleccionar una imagen PNG o JPG.
  4. Verificar en el inventario que la imagen aparece en la columna izquierda.
  5. Crear otro producto sin imagen y verificar que aparece el placeholder gris.
  6. Editar el producto con imagen, quitar la imagen y guardar. Verificar que el placeholder aparece en inventario.
